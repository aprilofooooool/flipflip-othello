# ぱたぱた！オセロっち

たまごっちのキャラクターが盤の上の石になって、「ぱたぱた」と返る、子ども向けの 8x8 リバーシ（オセロ）です。
インストールも通信も要りません。`index.html` を開くだけで遊べます。

> **ひこうしきファンメイド（非公式・非営利）。権利者とは無関係です。**
> 個人が楽しむためのファン作品です。公式の画像やセリフは使っていません。画像は自作の仮絵です。

## 遊び方

1. トップ画面で「ひとりであそぶ」か「ふたりであそぶ」をえらびます。
2. キャラクターをえらびます（ひとりのときは自分の 1 キャラ、相手の CPU はランダムです）。
3. CPU の強さ（やさしい／ふつう／つよい）や、先手、ハンデ（ふたりのときのみ）をえらびます。
4. 「スタート」をおします。えらび終わっていない項目があると、押せない理由が出ます。
5. 盤のマスをタップすると石を置けます。相手の石をはさむと、ぱたぱたと返ります。
6. 置ける場所がないときは、自動でパスになります。
7. 途中でやめても、次に開いたとき「つづきから」で再開できます（手ごとに自動で保存します）。

キャラクターは、いい手や角を取ったときなどに表情が変わり、ふきだしでしゃべります。

## ローカルで開く

1. このフォルダの `index.html` をダブルクリックします。
2. ブラウザが開いて、そのまま遊べます。

## GitHub Pages で公開する（公開するかどうかは自分で決めます）

公開すると、URL を知っている人は誰でも遊べます。非公式ファンメイドの表記を確認してから進めてください。

1. GitHub にログインし、右上の「+」から「New repository」をえらびます。
2. Repository name に `flipflip-othello` と入力し、「Create repository」をおします。
3. このフォルダで次のコマンドを実行して、`main` ブランチを push します（`<ユーザー名>` は自分の GitHub のユーザー名です）。

   ```
   git remote add origin https://github.com/<ユーザー名>/flipflip-othello.git
   git branch -M main
   git push -u origin main
   ```

4. GitHub のリポジトリ画面で「Settings」をひらきます。
5. 左のメニューの「Pages」をえらびます。
6. 「Build and deployment」の Source で「Deploy from a branch」をえらびます。
7. Branch を `main`、フォルダを `/ (root)` にして「Save」をおします。
8. 1〜2 分待ってから Pages の画面を開き直すと、公開 URL が出ます。
   ふつうは `https://<ユーザー名>.github.io/flipflip-othello/` です。
9. その URL を開いて、遊べることを確認します。

くわしい説明は GitHub の公式ドキュメントにあります: https://docs.github.com/ja/pages

## 画像をさしかえる

いまの画像は自作の仮絵です。本番の画像は、同じ名前のファイルで上書きするだけで反映されます。

- 保存場所: `assets/characters/<キャラid>/<感情>.png`
- くわしい決まりは `assets/README.md` を見てください。
- 仮絵をつくり直したいときは `tools/placeholder-art/README.md` を見てください。

## 増やす・変える（拡張ポイント）

| 増やしたいもの | 触るファイル |
|---|---|
| キャラ | `assets/characters/<id>/` に 6 画像を追加 ＋ `js/data/characters.js` に 1 エントリ |
| 画像の差し替え | 同名で上書き（拡張子を変える時は `characters.js` の `ext` を 1 か所） |
| ルール | `js/data/rulesets.js` に RuleSet を 1 エントリ（初期 UI は standard 固定） |
| 盤面サイズ | RuleSet の `size`（エンジン・AI・描画・テストは N×N 対応済み） |
| しきい値・待ち時間・難易度 | `js/config/constants.js` |
| 配色・角丸・アニメ時間 | `css/theme.css` |
| ロゴ画像 | `constants.LOGO_IMAGE` にパスを設定 |
| バージョン | `js/config/version.js` と `CHANGELOG.md` |

## テストの実行

このプロジェクトに Python は使いません。コマンドはプロジェクトのルート（このフォルダ）で実行します。

- ブラウザで確認する: `tests/test.html` をブラウザで開きます。結果が画面に出ます。
- コマンドで確認する（Node.js が必要です）:

  ```
  node tests/run-node.js
  node tests/static-check.js
  ```

  `run-node.js` は自動テスト、`static-check.js` は外部通信や禁止事項がないかの点検です。失敗すると終了コード 1 になります。
- 表示を手元で確かめるときの簡易サーバー: `node tests/tools/serve.js 8080` を実行し、`http://127.0.0.1:8080/` を開きます。

## iPhone で遊ぶときの注意

- iPhone の**マナーモード（消音）では音が鳴らないことがあります**。音を聞きたいときは、消音スイッチをオフにして、音量を上げてください。
- 縦向きで、幅 390〜430px・高さ 844px 以上の画面で 1 画面に収まるように作っています。iPhone SE など小さい画面は対象外です。
