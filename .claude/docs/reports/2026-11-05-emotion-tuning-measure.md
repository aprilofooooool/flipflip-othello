# 感情の出し方の見直し: 計測レポート

計測ツール: `tests/tools/measure-emotion.js`（実際の `reasons` / `reasonsFour` / `emotionOf` を呼ぶ）

## 条件

| 項目 | 値 |
|---|---|
| シード | 20261105（mulberry32） |
| `joy` | 「やさしい」対「ふつう」を 200 局。先手と後手を半分ずつ入れ替え。どちらも時間制限なし（深さだけで読む） |
| `rates` 2人用 | 同じ組み合わせで 100 局。ルールは standard と anti |
| `rates` 4人用 | 「やさしい」1席 + 深さ3のCPU 3席 を 100 局（「やさしい」の色は局ごとに順番に変える） |
| 勝敗が決まった値 | `abs(score) >= WIN_SCORE/2` の手は除く |

## joy の結果

「やさしい」席が打った全部の手の評価の変化（勝敗が決まった値は除く）の上位1割（90 パーセンタイル）。設計書の 120 はこの数え方。

| ルール | 計測値 | 基準(標準の計測値 126)に対する比 | 範囲(88〜163)内か | 判断 |
|---|---|---|---|---|
| standard | 126 | 1.00 | 内 | 変更なし（`Otc.Const` の 120 のまま） |
| mini | 93 | 0.74 | 内 | `thresholds` なしのまま（`Otc.Const` に任せる） |
| anti | 222 | 1.76 | 外 | `JOY_DELTA` を 236 から 222 に変更 |
| mini-anti | 306 | 2.43 | 外 | `JOY_DELTA` を 320 から 306 に変更 |

- 基準は計測値の 126 のまま（±30% で 88〜163）。計画の最初の 120 を基準にすると範囲は 84〜156 になるが、4つの判断（変更なし・変更なし・変更・変更）はどちらでも同じ。
- mini と mini-anti の rates（1局あたりの回数）は計測していない。
- `PANIC_DELTA` と `ADVANTAGE_EVAL` は変えていない。
- 最初の計測は「正の値だけの上位1割」で計ったため標準が 163 になり、設計書の 120 と合わなかった。設計書は全部の手で数えていたので、全部の手の数え方に直した。

## rates の結果（1局あたりの回数）

打った直後を `own`、ほかの人の手のあとを `other` とする。パスは `pass` に分けて数え、`selfNegative` には入れない。

| 区分 | 2人用 standard | 2人用 anti（JOY 222） | 4人用 |
|---|---|---|---|
| own.joy | 3.73 | 3.05 | 2.01 |
| other.anger | 2.66 | 0 | 0.58 |
| other.sadness | 2.87 | 0 | 0.85 |
| other.panic | 2.71 | 0.36 | 0.98 |
| other.joy | 0 | 0.82 | 0 |
| pass.panic | 1.24 | 0.04 | 0.12 |
| selfNegative | 0 | 0 | 0 |

参考: anti を以前の `JOY_DELTA` 236 で計ると own.joy は 2.41 だった。

## 気になる点

- 標準の計測値 126 は設計書の 120 と近く、`JOY_DELTA` = 120 のまま own.joy は 3.73 で設計書どおり。
- anti は own.joy 3.05 で、標準に近い出方になった。
