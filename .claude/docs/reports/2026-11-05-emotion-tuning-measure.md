# 感情の出し方の見直し: 計測レポート

計測ツール: `tests/tools/measure-emotion.js`（実際の `reasons` / `reasonsFour` / `emotionOf` を呼ぶ）

## 条件

| 項目 | 値 |
|---|---|
| シード | 20261105（mulberry32） |
| `joy` | 「やさしい」対「ふつう」を 200 局。先手と後手を半分ずつ入れ替え。どちらも時間制限なし（深さだけで読む） |
| `rates` 2人用 | 同じ組み合わせで 100 局。ルールは standard と anti |
| `rates` 4人用 | 「やさしい」1席 + 深さ3のCPU 3席 を 100 局（「やさしい」の色は局ごとに順番に変える） |
| 勝敗が決まった値 | `abs(score) >= WIN_SCORE/2` の手は除く |

## joy の結果

「やさしい」席の、評価が上がった手の上位1割（90 パーセンタイル）。

| ルール | 計測値 | 基準(120)に対する比 | 範囲(84〜156)内か | 判断 |
|---|---|---|---|---|
| standard | 163 | 1.36 | 外 | 変更なし（`Otc.Const` のまま。下の「気になる点」参照） |
| mini | 114 | 0.95 | 内 | `thresholds` なしのまま（`Otc.Const` に任せる） |
| anti | 259 | 2.16 | 外 | `JOY_DELTA` を 236 から 259 に変更 |
| mini-anti | 320 | 2.67 | 外 | `JOY_DELTA` 320 のまま（変更なし） |

- `PANIC_DELTA` と `ADVANTAGE_EVAL` は変えていない。
- 別シード(1)で standard を計り直しても 163 で、ぶれは小さい。

## rates の結果（1局あたりの回数）

打った直後を `own`、ほかの人の手のあとを `other` とする。パスは `pass` に分けて数え、`selfNegative` には入れない。

| 区分 | 2人用 standard | 2人用 anti（JOY 259） | 4人用 |
|---|---|---|---|
| own.joy | 3.73 | 1.64 | 2.01 |
| other.anger | 2.66 | 0 | 0.58 |
| other.sadness | 2.87 | 0 | 0.85 |
| other.panic | 2.71 | 0.36 | 0.98 |
| other.joy | 0 | 0.82 | 0 |
| pass.panic | 1.24 | 0.04 | 0.12 |
| selfNegative | 0 | 0 | 0 |

参考: anti を以前の `JOY_DELTA` 236 で計ると own.joy は 2.41 だった。

## 設計書の予想との比較

| 項目 | 設計書の予想 | 計測 | 見立て |
|---|---|---|---|
| 標準の own.joy（§4） | 約 3.7 | 3.73 | 一致 |
| 打った直後の悪い感情（§5） | 0 | selfNegative = 0 | 一致 |

## 気になる点

- `joy` セクションの定義（「やさしい」席の正の変化の上位1割）で standard を計ると 163 で、設計書の 120 より大きい。ただし `JOY_DELTA` = 120 のまま `rates` を計ると own.joy は 3.73 で設計書どおり。120 の出どころは別の数え方だった可能性がある。値の調整はしていない。
- anti は 259 にすると own.joy が 1.64 に下がる。standard の約半分で、やや出にくい。
