## 準備（iPhone で開く方法）

GitHub Pages はまだ公開していません。また、付属の `tests/tools/serve.js` は安全のため PC 自身（127.0.0.1）からしか開けません。iPhone で開くには次のどちらかが必要です。

- A. GitHub Pages に公開する（あなたの指示で push とリポジトリ作成を行う。README の手順どおり）
- B. 同じ Wi-Fi の iPhone から PC に入れるよう、LAN 向けに待ち受けるサーバーを一時的に立てる（Windows のファイアウォール許可が出る場合あり）

項目 8（PC の Chrome でダブルクリック）は準備なしで確認できます。
