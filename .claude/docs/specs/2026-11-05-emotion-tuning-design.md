# 感情の出し方の見直し案（2人用・4人用）

- 作成日: 2026-11-05
- 状態: 案（未承認・未実装）
- きっかけ: 手動テストで次の2つを感じた（2人用・4人用とも）。
  - パニックの出方が偏っている。
  - 自分が打った直後にパニックが出る。
- 目的: 次の2つを直す。
  - 出るタイミングがおかしい（打った本人に嫌な感情が出る）。
  - 同じ場面でいつも同じ感情が出る（反応がワンパターン）。
  - パニックの回数を減らすことは目的にしない（ユーザー判断）。

## 1. 計測の方法

子どもの代わりに CPU「やさしい」を1席に置いて自動で対局し、その席に出る感情を数えた。判定の計算は今のコードと同じ。

- 2人用: 「やさしい」対「ふつう」を300局、「やさしい」対「つよい」を100局（標準 8x8）。
- 4人用: 「やさしい」1席 と CPU 3席（深さ3）で100局。
- スクリプトは作業用フォルダに置いた（`emo-measure.js` / `emo-analyze.js` / `emo-cool.js`）。採用するなら `tests/tools/` に移す。

## 2. 今の出方（「やさしい」席、1局あたりの回数）

| 対局 | よろこぶ | パニック | かなしい | おこる |
|---|---|---|---|---|
| 2人用 対「ふつう」 | 1.3 | 5.0 | 3.3 | 3.6 |
| 2人用 対「つよい」 | 0.9 | 7.0 | 3.1 | 3.6 |
| 4人用 | 2.1 | 4.0 | 0.3 | なし |

分かったこと:

1. **自分の手の直後のパニックが多い。**
   - 2人用（対「ふつう」）では、自分の悪い手のあとのパニックが 2.1 回。パニック全体の 4 割にあたる。
   - 4人用では 1.4 回。角のななめ隣に置いたり、置いたあとに置ける場所が減ったりすると出る。
2. **よろこぶが少ない。** 2人用のしきい値 197 は、「ふつう」と「やさしい」の両方の手を合わせた上位1割で決めた値。そのため「やさしい」の手はほとんど届かない。
3. **4人用では「かなしい」がほぼ出ない。** 石を5個返されると、その時点でパニックの線も越える。優先順でパニックが勝つ。
4. **出来事ごとに感情が1つに決まっている。** 角を取られたら必ず「おこる」、たくさん返されたら必ず「かなしい」になる。
5. （前回の説明の訂正）「石を取られていないのに、ほかの人の手でパニックが出る」は、計測では 0% だった。

## 3. 見直しの原則（2人用・4人用で共通）

1. **打った本人には嫌な感情を出さない。** 自分の手の直後は「よろこぶ」か「何も出ない」。パスは打った手ではないので、今どおりパニック。
2. **やられた出来事では、感情を重みつきのランダムで選ぶ。** 出来事ごとに、いちばん出やすい感情を決めておく。

   | 出来事（やられた側） | おこる | かなしい | パニック |
   |---|---|---|---|
   | 角を取られた | **50%** | 25% | 25% |
   | たくさん返された | 25% | **50%** | 25% |
   | 形勢が大きく悪くなった（上の2つがないとき） | — | — | 100% |

   - 角を取られて、同時にたくさん返されたときは、「角を取られた」の重みで選ぶ。
   - 乱数はゲームの乱数（`rng`）を使う。テストで結果を固定できるようにするため。
3. **同じ人に同じ感情が2回続いたら、3回目は別の感情にする。** 重みの表で、その感情を除いた残りから選ぶ。残りがない（パス・形勢だけ）ときはそのまま。
4. **しきい値は「子どもの席に1局で何回出るか」で決める。** 今の決め方は「全部の手の上位1割」なので、強い側の手に引っぱられる。

## 4. 2人用の具体案

| 項目 | 今 | 案 |
|---|---|---|
| 打った本人のパニック（悪い手） | 評価が 331 以上下がると出る | **出さない** |
| よろこぶ `JOY_DELTA` | 197 | **120**（「やさしい」の手の上位1割） |
| かなしい `SADNESS_FLIPS` | 5個以上 | 5個以上（そのまま） |
| 相手のパニック `PANIC_DELTA` | 331 | 331（そのまま） |
| やられた側の感情 | 決まった1つ | **§3 の重みつきランダム** |

案にしたときのおおよその回数（対「ふつう」、計測から計算した値）:

| | よろこぶ | おこる | かなしい | パニック |
|---|---|---|---|---|
| 今 | 1.3 | 3.6 | 3.3 | 5.0 |
| 案 | 3.7 | 2.7 | 2.7 | 4.3 |

案のパニック 4.3 回の内訳: パス 1.6 / 角・返されたのランダム 1.8 / 形勢 0.9。打った直後のパニックは 0 になる。

アンチ（角を取ると損）の扱い:

- 今は、角を取った本人がパニックになる。
- 案では、本人には何も出さない。相手がよろこぶだけにする。

6x6・アンチ・6x6アンチのよろこぶのしきい値は、同じ方法で計り直す。

## 5. 4人用の具体案

| 項目 | 今 | 案 |
|---|---|---|
| 打った本人のパニック | 評価が 50 以上下がると出る | **出さない** |
| ほかの人の手でのパニック（形勢） | 評価（置ける場所の数を含む）が 50 以上下がる | **取られた石の価値**（石・場所・角。置ける場所の数は入れない）が 50 以上 |
| たくさん返された | 5個以上 | **4個以上** |
| やられた側の感情 | 決まった1つ | **§3 の重みつきランダム（「たくさん返された」の行）** |
| 色が全部消えた・パス | パニック | そのまま |

- 4人用で「角を取られた」は使わない。角はだれの物でもないので、取られた人が決まらない。
- 【私の判断】設計（§6.2）では、4人用に「おこる」はなしと決めてあった。案では、たくさん返されたときに限って「おこる」を出す。返された人がはっきりしているので、2人用と同じ扱いにしても不自然ではないため。違えば「かなしい 65% / パニック 35%」にする。

案にしたときのおおよその回数: よろこぶ 2.1 / おこる 0.6 / かなしい 1.2 / パニック 1.4（今は よろこぶ 2.1 / パニック 4.0 / かなしい 0.3）。

## 6. 画面全体の演出（人間が2人以上のとき）

- 今: 優先順（おこる → パニック → かなしい → よろこぶ）で決まる。そのため、相手の嫌な感情が、打った人のよろこびに勝つ。
- 案: 打った人の感情を先にする。打った人に感情がなければ、今の優先順で選ぶ。

## 7. 今回は入れないもの

- キャラごとの性格で重みを変える（例: うさぎは怒りやすい）。まず全員共通の重みで試す。物足りなければ足す。
- 感情の強さを2段階にする（弱いときは顔だけ）。
- 強さの設定ごと・序盤／終盤ごとにしきい値を変える。
