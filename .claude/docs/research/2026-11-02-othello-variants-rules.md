# オセロ派生ゲーム（ルール変更系）調査記録

- 調査日: 2026-11-02
- 目的: 家庭向けオセロアプリ（CPU対戦・キャラクターあり）に入れる「盤面は概ね標準のまま、ルールだけ違う」モードの候補選定
- 関連: 盤面が違う派生は `othello-variants-board.md`、ハンデ戦の詳細は `2026-10-29-handicap-rules.md`
- 信頼度の表記: **高** = 公式団体の規則・出典つき百科事典で一致 / **中** = 一次資料を引く個人サイトや商品紹介記事 / **出典弱** = 個人ブログ・攻略サイトのみ / **未確認** = 根拠が見つからない
- BoardGameGeek はアクセス拒否（HTTP 403）で本文を読めなかった。メガハウス公式サイトのルールページも見つからなかった。

## 1. 基準となる標準ルール（比較の土台）

### 1.1 世界オセロ連盟（WOF）の公式ルールと世界選手権規則

| 項目 | 内容 | 出典 |
|---|---|---|
| 初期配置 | 中央4マスに黒2・白2を対角に置く（図で固定） | WOF 公式ルール |
| 先手 | 黒が常に先手 | WOF 公式ルール |
| 着手条件 | 相手の石を1つ以上挟んで返せるマスにだけ置ける。挟んだ石は全方向すべて返す（返したくなくても返す） | WOF 公式ルール |
| パス | 返せる手が無いときだけ手番を失う。打てる手があるのにパスはできない | WOF 公式ルール |
| 終局 | 双方とも打てなくなったら終局。64マス埋まる前に終わることがある | WOF 公式ルール |
| 勝敗 | 自分の色の石が多い方が勝ち | WOF 公式ルール |
| 空きマス | 勝者の石数に加算（WOC規則 IV.8） | WOC 規則 |
| 引き分け | 32-32 として記録（WOC規則 IV.8） | WOC 規則 |
| 石切れ | 手元の石が尽きたら、審判が相手から必要数を移す（WOC規則 IV.2） | WOC 規則 |
| 持ち時間 | 予選 30分/人、準決勝 35分、決勝 40分。25分未満では行わない（WOC規則 IV.1） | WOC 規則 |
| 時間切れ | 時間切れ側の負け。追加2分で続行し、非違反側は最低 33-31 勝ち。再度時間切れなら 64-0（IV.6） | WOC 規則 |

出典:
- https://www.worldothello.org/about/about-othello/othello-rules/official-rules/english
- https://woc2018.worldothello.org/participate/woc-rules （2018年WOC規則）
- 参考（米国連盟）: https://usothello.org/?p=43 — 石切れは「相手から必要なだけ受け取る」(1.4)、同数は tie (4.2)

### 1.2 日本オセロ連盟（JOA）競技ルール

| 項目 | 内容 | 出典 |
|---|---|---|
| 先後 | 試合前の伏せ石で決める（第1項） | JOA 競技ルール |
| パス | 打てる箇所が無いときはパスを宣言して時計を押す。打てるのにパスは不正着手（第5項・第8項） | JOA 競技ルール |
| 終局 | 対局者双方が石を置けなくなった状態（第14項） | JOA 競技ルール |

| 引き分け | 32-32 のときは「引き分け勝ち」の権利者（伏せ石で決める）の勝ち（第1項・第16項） | JOA 競技ルール |
| 持ち時間 | 原則すべての対局で対局時計を使う。時間は大会ごとに決める（第2項） | JOA 競技ルール |

### 1.3 WOF と JOA の違い（アプリ実装に関係する点）

| 項目 | WOF/WOC | JOA | アプリでの扱いの考え方 |
|---|---|---|---|
| 空きマス | 勝者に加算 | 勝者に加算（2014年以降） | 一致。旧資料の「折半」は改訂前の規則 |
| 32-32 | 引き分け（32-32 と記録） | 大会では「引き分け勝ち」権利者の勝ち | 家庭向けなら「引き分け」表示で問題なし |
| 石切れ | 相手から移す | 相手の石を使ってよい | 一致。アプリは石数を個人別に持たず、64個共通にするのが簡単 |

### 1.4 「Iago」について

依頼文の「Iago」は特定できなかった（未確認）。GNOME の Reversi アプリ **Iagno** と仮定すると、man ページに次のオプションがある。
- `--usual-start` / `--alternative-start` / `--random-start`: 初期配置を2種から選ぶ、またはランダム
- `--classic`（多い方が勝ち）/ `--reverse`（少ない方が勝ち）
- 出典: https://man.archlinux.org/man/iagno.6.en
- Iagno のパス・石切れ・空きマスの扱いは man ページに記載なし（未確認）。

## 2. 標準オセロと歴史的リバーシの違い（混同注意）

| 項目 | 標準オセロ（1973〜） | 歴史的リバーシ（1880年代、Waterman/Jaques） | 主な出典 |
|---|---|---|---|
| 初期配置 | 中央4マスに対角（クロス）で固定 | 盤は空で開始。最初の4手（各2手）を中央4マスに交互に置き、この間は裏返しなし。結果として対角型と平行型（パラレル）の2通りが生じる | en.wikipedia Reversi / mastersofgames / mindsports / solitairelaboratory |
| 石の数 | 64個を共通で使う（WOF は各32個を持つが不足時は相手から移す） | 各自32個。相手がパスすると自分が先に石切れになり、相手が最後に余分に打てる | solitairelaboratory（Berkeley 1890 を引用）、ja.wikipedia 表「着手回数制限 32手」 |
| 着手回数 | 無制限 | 19世紀は32手まで | ja.wikipedia（原典 Berkeley 1890） |
| パス | 打てなければパス | パス（ja.wikipedia 表・solitairelaboratory）。ただし「片方が打てないと即終局」とする資料もある（下記の食い違い） | — |
| 石の色 | 黒白 | 赤と緑など。黒赤・赤白も | ja.wikipedia / mastersofgames |
| 先手 | 黒 | コイントスで決定 | mastersofgames（出典弱） |
| 20世紀のリバーシ | — | 1907年『世界遊戯法大全』ではオセロと同じクロス配置。20世紀にはクロス・パラレル・オリジナルが混在 | ja.wikipedia / en.wikipedia |

出典:
- https://en.wikipedia.org/wiki/Reversi
- https://ja.wikipedia.org/wiki/オセロ_(ボードゲーム) （「オセロとリバーシの違い」表。原典: Berkeley 1890、松浦政泰 1907、長谷川五郎 1974）
- https://solitairelaboratory.com/abstract/reversi.html （中: 個人サイトだが Berkeley 1890 ほか一次資料を明示）
- https://www.mastersofgames.com/rules/reversi-othello-rules.htm （出典弱: 販売店の解説）
- https://www.mindsports.nl/index.php/the-pit/545-othello （中）

食い違い:
- **石切れで終局するか**: 各自32個で尽きたらどうなるかの原文（Berkeley 1890）は未確認。solitairelaboratory は「相手が余分に打てる」とするが、「その時点で終局」とする資料は見つからなかった。
- **片方が打てない時**: mastersofgames は同じページ内で「双方が打てなければ終局」と「片方が打てなければ終局」の両方を書いている。solitairelaboratory は「片方が打てないと即終局」を「誤ったルール」と明記。ja.wikipedia 表は19世紀リバーシも「パス」。→ 「パス」が多数派。
- **初期配置で裏返しが起きるか**: en.wikipedia は「後手の2手目で1枚返してよい／返さねばならない変種もある」と記載。基本は裏返しなし。

## 3. 派生ルール一覧

### 3.1 アンチオセロ（アンチリバーシ / Reversed Reversi / Misère）— 信頼度: 高

- 差分: **勝敗判定だけ逆**（自分の色の石が少ない方が勝ち）。初期配置・着手・裏返し・パス・終局は標準と同じ。引き分けあり。
- 空きマスの扱い: 標準の「勝者に加算」をそのまま当てはめると勝者の石が増えて矛盾する。どの資料も規定なし（未確認）。アプリでは「空きマスは数えない」と明示する必要がある。
- 出典:
  - https://en.wikipedia.org/wiki/Reversi （Anti-Reversi 節。出典 samsoft.org.uk "About Anti-Reversi"）
  - https://man.archlinux.org/man/iagno.6.en （`--reverse`）
  - https://solitairelaboratory.com/abstract/reversi.html （Misère Reversi）
  - https://rarepike.com/reversi/variants/ （出典弱）
- 商標: 名称に「オセロ」を使う場合の注意は 4章を参照。

### 3.2 ハンデ戦（置き石）— 信頼度: 中〜高

- 差分: 隅に黒石を1〜4個置いた状態から開始。下手が黒、上手が白を持ち、**白（上手）が先手**。それ以外は標準。
- JOA 競技ルール本文にはハンデ戦の規定なし（第19項は身体的ハンディキャップへの配慮で別物）。
- 出典:
  - https://ja.wikipedia.org/wiki/オセロ_(ボードゲーム) （「ハンデキャップ」節。原典: 長谷川五郎 1981 pp.13-22）
  - https://www.othello.gr.jp/rule
  - 研究（参考）: https://ipsj.ixsq.nii.ac.jp/records/91362 （隅ハンデは1枚の差が大きすぎ、微調整に向かないという指摘）
- 別案（出典弱）: Sid Cox 案「下手が好きな時に1回パスできる」（solitairelaboratory で紹介）。
- 詳細は `2026-10-29-handicap-rules.md`。

### 3.3 歴史的リバーシ（自由初期配置）— 信頼度: 中

- 差分: 盤は空で開始し、最初の4手を中央4マスに交互に置く（裏返しなし）。対角型か平行型かがプレイヤーの選択で決まる。以後は標準と同じ。
- 石数制限（各32個）を再現するかは任意。再現すると「パスした側が先に石切れ→相手が最後に連続で打つ」ことになる（solitairelaboratory）。この挙動の一次資料原文は未確認。
- 出典: 2章を参照。

### 3.4 ランダム初期配置 / XOT — 信頼度: 高（XOT）、出典弱（その他）

- XOT: 計算機評価で互角と判定された序盤の大きな一覧から1つを無作為に選び、**最初の8手を自動で打った局面から開始**（黒の9手目から対局）。目的は定石暗記の排除。他は標準ルール。
  - 出典: https://worldothello.org/about/tournaments/confederate-championships/european-othello-tournaments/european-xot-championship/what-is-xot
  - 一覧の件数は資料により 10,785 件（出典弱: https://zff.dev/neuhaus/othello-xot-trainer ）。WOF ページは件数を書いていない。正確な件数は未確認。
  - 同一局面を先後入れ替えで2局打つかは WOF ページに記載なし（未確認）。
- Iagno の `--random-start`: 標準配置と別配置（平行型と推定、未確認）の2種から無作為に選ぶ。
- 中央4石の色をランダムにする・近傍マスにランダム配置する等: rarepike のみ（出典弱）。

### 3.5 時間制限・持ち時間ルール — 信頼度: 高

- 差分: 盤上ルールは標準。各自に持ち時間を与え、使い切ったら負け。
- 公式値: WOC は 30〜40分/人（最低25分）。JOA は大会ごとに設定。時間切れ時の石数処理は WOC（33-31 保証・64-0）と JOA（勝手打ちで石差を決める場合あり）で異なる。
- 出典: 1.1・1.2 の WOC 規則 / JOA 競技ルール。
- 「スピードリバーシ」（1分・3〜5分等の区分）は rarepike のみ（出典弱）。

### 3.6 多人数オセロ（メガハウス「みんなでオセロ」/「4人対戦オセロ」）— 信頼度: 中

- 差分:
  - 石は4面が4色の専用石。2人なら2色、3人なら3色、4人なら4色。
  - 初期配置: 各色2個ずつ計8個を決まった場所に置く（配置図は未確認）。
  - 以後は通常のオセロと同じ（挟んで返す）、最後に石が多い人が勝ち。
  - イベントカード: 「ボム」（置いた石の周囲8マスを自分の色にする）、「クロス」（縦横すべてを自分の色にする）など。枚数・使用回数・使用条件は未確認。
  - パス・引き分けの扱いは未確認。
- 出典（いずれも商品紹介記事。メーカーの説明書は未確認）:
  - https://kakakumag.com/hobby/?id=7197
  - https://www.excite.co.jp/news/article/E1385363923875
  - https://www.soundhouse.co.jp/products/detail/item/304056/
- 食い違い: 商品名が「みんなでオセロ」（税込3,675円、2013年頃の記事）と「4人対戦オセロ」（税込2,980円）の2つあり、同じ商品か改版かは未確認。

### 3.7 ローリット（Rolit）— 信頼度: 中

- 商品: Goliath 社の商品名（Rolit）。ja.wikipedia は「球体の石を用いる4人対戦の派生ゲーム」と記載し、Goliath の商品ページを出典にしている。デザイナー・初出年は BoardGameGeek を読めず未確認。
- 差分（標準オセロとの違い）:
  - 2〜4人。4色のボール（各ボールが4色に塗り分けられ、転がして色を変える）。
  - 初期配置: 人数に関係なく中央に4色を1個ずつ（正方形）置く。
  - 着手: **既に置かれたボールに隣接する空きマス**に置く。挟めるなら挟まなければならない。
  - 救済ルール: 自分の色が盤上に無い、または挟めない場合は、任意のボールに隣接する空きマスに置いてよい（**パスが無い**）。
  - 裏返し: 新しく置いたボールと同色のボールで挟んだ他色をすべて自分の色に返す。
  - 終局: 64マスがすべて埋まったら終了（全ボールを置き終えたら）。
  - 勝敗: 自分の色のボールが最も多い人が勝ち。複数ラウンド制では勝ったラウンド数、同数なら合計点。1ラウンド内の同数の扱いは未確認。
  - 簡易版: 6×6・4×4 の盤で遊ぶ案（Rolit Travel の説明）。
- 出典:
  - https://ultraboardgames.com/rolit/game-rules.php （出典弱寄り: ルール転載サイト）
  - https://rulespal.com/rolit/rulebook （出典弱寄り: ルール転載サイト）
  - https://rulespal.com/rolit-travel/rulebook
  - https://www.proshop.se/Leksaker/Goliath-Rolit/3432872 （販売店）
  - https://ja.wikipedia.org/wiki/オセロ_(ボードゲーム) （派生ゲーム節）
- 食い違い:
  - **色の決め方**: ultraboardgames は「座った位置に最も近い盤の色」、rulespal は「手番順に赤→黄→緑→青（2人なら赤・緑）」。
  - **裏返しの方向**: ultraboardgames は「8方向すべて確認して返す」、rulespal は「1本の線で挟む。複数の選択肢があれば戦術的に良いものを選ぶ」とも読める記述。どちらが原典どおりか未確認（翻訳の差の可能性）。
- 商標: 「Rolit」は商品名。アプリでは名称を使わず「4人対戦」等の一般名にするのが安全（商標登録の有無は未確認）。

### 3.8 壁石・ブロック石（置けないマス）入り — 信頼度: 出典弱

- 差分: 開始前に無色の石（ブロック）を空きマスに置く。そのマスには打てず、盤の端と同じ扱い（挟みの線がそこで止まる）。中央4マスの隣には置かない。以後は標準。個数は規定なし。
- 出典:
  - https://groups.google.com/g/rec.games.abstract/c/pCoMIqZYStE/m/o3BunWd0H2AJ （2001年、T. Mogensen によるニュースグループ投稿。10×10 向きの提案）
  - https://dgsoftware.itch.io/othello-2-dash-4 （個人制作ゲームの「Blocked Tiles」10/20/30% ランダム除去）
  - 盤の穴の考え方は MacBeth（Freeling、六角盤に19個の穴）にもある: https://solitairelaboratory.com/abstract/reversi.html
- 公式団体・商品での採用例は見つからなかった（未確認）。

### 3.9 特殊石（両面同色・裏返らない石など）— 未確認

- 公式団体・メーカー・百科事典で、この種のルールを定めた資料は見つからなかった。
- 近いものは 3.6 のイベントカード（周囲や縦横を一括で自分の色にする）のみ。
- アプリ独自ルールとして作る場合は、出典なしの独自仕様として扱う必要がある。

### 3.10 1手で2回置く系 — 出典弱

- 「プログレッシブ・リバーシ」（1手目1回、2手目2回…と打つ回数が増える）: rarepike のみ。https://rarepike.com/reversi/variants/
- 「毎手番2回打つ」形のオセロ変種は見つからなかった（未確認）。
- 標準ルールでも、相手がパスすると同じ側が連続で打つことはある（WOF 公式ルール）。

## 4. 商標上の注意

- 「オセロ」「Othello」は株式会社オセロの登録商標。メガハウスが専用使用権を持つ（ja.wikipedia。出典は同記事の脚注）。英語圏では商標が Anjar Co. に帰属とする記述もある（mindsports）。
- 一般名は「リバーシ」。アプリ内のモード名に「アンチオセロ」等「オセロ」を含む名前を使うかどうかは、本調査の範囲外（法的判断は未確認）。
- 「Rolit」は Goliath 社の商品名。「みんなでオセロ」「4人対戦オセロ」はメガハウスの商品名。
